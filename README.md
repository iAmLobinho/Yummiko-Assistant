# 💜 Yummiko — Assistente Virtual

A Yummiko é uma assistente virtual desenvolvida com HTML5, CSS3 e JavaScript, criada para facilitar tarefas do dia a dia por meio de comandos de voz ou texto.

O projeto busca oferecer uma experiência simples, prática e intuitiva, sem necessidade de avatar ou personagem visual.

# ✨ Funcionalidades

- 🎙️ Reconhecimento de voz: permite interagir com a assistente por comandos falados.
- 🔊 Respostas por voz: transforma as respostas em áudio utilizando síntese de fala do navegador.
- 🌤️ Clima: consulta temperatura, sensação térmica, umidade e previsão do tempo.
- 📅 Agenda e lembretes: permite cadastrar e organizar compromissos.
- 🧮 Calculadora: realiza operações matemáticas por texto ou voz.
- 🔎 Pesquisa na web: facilita pesquisas na internet.
- 💬 Integração com WhatsApp: prepara mensagens para envio pelo WhatsApp.
- ⚙️ Comandos personalizados: permite cadastrar comandos próprios.
- 🎨 Interface responsiva: adaptada para computadores e dispositivos móveis.

# 📱 Compatibilidade

A Yummiko foi desenvolvida para funcionar em navegadores modernos de computadores e celulares., algumas funcionalidades dependem do suporte do navegador:
- O reconhecimento de voz pode variar conforme o navegador e o dispositivo.
- A síntese de voz utiliza as vozes disponíveis no sistema.
- A consulta do clima e a pesquisa na web precisam de conexão com a internet.
- Os lembretes são armazenados localmente e dependem da execução da página para serem verificados.

# 🔒 Privacidade

As configurações, os comandos personalizados e os lembretes são armazenados localmente no navegador por meio do LocalStorage.

As consultas meteorológicas utilizam um serviço externo. O uso do reconhecimento de voz também depende das permissões e dos recursos oferecidos pelo navegador.
